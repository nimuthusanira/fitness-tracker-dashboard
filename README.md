# 🏋️ Fitness Tracker Dashboard

A responsive web application built with React to help users monitor workouts, track daily health goals, and visualize fitness progress over time.

---

## 🚀 Live Demo
* **Live Application:** [View Live on Vercel](https://fitness-tracker-dashboard.vercel.app/) 



---

## ✨ Features
* **Workout Logging:** Record and categorize exercises, sets, reps, and durations.
* **Progress Analytics:** Visual charts tracking weekly and monthly activity.
* **Goal Setting:** Set custom fitness targets and monitor completion status.
* **Responsive Design:** Optimized layout for desktop, tablet, and mobile screens.

---

## 🛠️ Technology Stack
* **Frontend:** React, HTML5, CSS3 / Tailwind CSS
* **State Management:** React Hooks (useState, useEffect)
* **Deployment:** Vercel
* **Tooling:** Vite / Create React App, Git
